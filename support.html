Support

Find quick answers below. If a problem continues, email us without including private conversation text or exported Library files.

Report a problem

A highlight does not appear after refresh

Reload the ChatGPT tab after installing or updating the extension. Confirm that the source conversation still contains the selected text.

Library opens the conversation but not the exact passage

Long conversations may need progressive recovery. Use the continuation action shown by Highlight to search earlier content or match by text.

Where is my data stored?

Highlight stores its Library in chrome.storage.local on the current Chrome profile. There is no Highlight account or cloud synchronization.

How do I create a backup?

Open the Library, choose Data, and select Export JSON. Keep the downloaded file private. Use Import JSON to restore it later.

How do I remove saved data?

Delete individual highlights or selected results from the Library. Uninstalling the extension removes its local Chrome storage from that profile.

What should I include in a bug report?

Include the Highlight version, Chrome version, steps to reproduce, and a screenshot with private content removed. Do not post exported JSON files or sensitive conversation text.

Known limitations

  • Highlight currently supports chatgpt.com and the legacy chat.openai.com host.
  • Restoration depends on the source text and page structure remaining sufficiently similar.
  • Moving a Library between browsers or devices requires manual JSON export and import.
  • There is no Highlight cloud sync or automatic cross-device synchronization.
